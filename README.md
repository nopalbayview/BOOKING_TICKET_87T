## About 87-trans

**87-trans** adalah aplikasi manajemen transportasi modern yang dibangun menggunakan arsitektur *monorepo*. Proyek ini memisahkan sistem secara bersih antara **Laravel** di sisi backend (sebagai penyedia RESTful API) dan **React + Vite** di sisi frontend (sebagai *Single Page Application*).

### Tech Stack Utama:
* **Backend:** Laravel 13, PHP 8.5, Postgresql Database.
* **Frontend:** React, Vite, Tailwind CSS.
* **Version Control:** Git & GitHub (Branch: `main`).
